# Solar-Driven IoT-Based Waste Management System & Battery Management System (BMS)

## 📌 Overview
This repository contains two embedded system projects focused on real-time monitoring, automation, and validation:
1. Solar-powered IoT Waste Management System
2. Battery Management System (BMS) with protection

Both projects demonstrate skills in embedded systems, sensor interfacing, testing, and validation.

---

## 🚀 Features
- Real-time monitoring of parameters (waste level, voltage, current, temperature)
- IoT-based remote monitoring using ThingSpeak
- Fault detection and protection mechanisms
- Solar-powered energy-efficient design
- Automated control using actuators (servo motor, relay)

---

## 🛠️ Components Used
- ESP32 / Arduino Uno  
- Ultrasonic Sensor  
- Moisture Sensor  
- Current, Voltage, Temperature Sensors  
- GSM Module  
- Relay Module, Buzzer  
- Servo Motor, DC Motor  
- LCD Display  
- Lithium-ion Battery + Solar Panel  

---

## ⚙️ Working Principle
- Sensors collect real-time data  
- Microcontroller processes inputs  
- System triggers outputs (relay, buzzer, servo) based on thresholds  
- Data is transmitted via GSM to ThingSpeak for monitoring  

---

## 🧪 Testing & Validation
- Functional testing of all modules  
- Sensor calibration and verification  
- Fault condition testing (overvoltage, temperature)  
- Communication reliability testing

## 📊 Results
